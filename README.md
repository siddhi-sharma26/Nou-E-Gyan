# NOU LMS – Learning Management System

## 📖 About the Project

NOU LMS is a web-based Learning Management System developed to support online education by providing students with access to digital study materials and academic information. The platform includes separate Admin and Student sections to manage learning resources and student activities efficiently.

## ✨ Features

* **Admin Dashboard:** Manage students, courses, and study materials.
* **Study Materials:** Upload and access digital learning resources.
* **Course Management:** Organize courses and academic information.
* **Student Management:** View and manage student records.
* **Notifications:** Share important notices and updates.
* **Question Management:** Manage academic questions and discussions.
* **Feedback & Complaints:** Handle student feedback and complaints.
* **User Authentication:** Provide login access to the system.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** Java, JSP, Servlets
* **Database:** MySQL
* **Server:** Apache Tomcat
* **Development Tool:** NetBeans IDE
* **Database Tool:** XAMPP / phpMyAdmin

## ⚙️ Installation and Setup

1. Clone or download this repository.
2. Install **JDK, NetBeans IDE, Apache Tomcat, and XAMPP**.
3. Start MySQL using the XAMPP Control Panel.
4. Open phpMyAdmin and create a database named `nou`.
5. Import the project's database SQL file, if available.
6. Open the project in NetBeans IDE.
7. Verify the MySQL connection settings in `src/java/connect/DbManager.java`.
8. Configure Apache Tomcat as the project server.
9. Run the project from NetBeans.

## 🗄️ Database Configuration

The application uses MySQL for storing application data.

* **Database Name:** `nou`
* **Host:** `localhost`
* **Port:** `3306`

Update the database connection settings according to your local MySQL configuration.
